# AFAQ SUPPLY — Suspended Clothing Rail Collection Engine

## 1. Overview
The **Clothing Rail Section** reproduces the 5.5s – 8.0s and 8.0s – 11.5s sequence of the reference video. It features garments suspended on hangers along a horizontal tension cable.

---

## 2. Technical Features
- **Tension Cable:** Continuous horizontal rail line spanning the viewport.
- **Wooden Hanger Mechanics:** Custom SVG hanger hook with realistic contact point and suspended garment drop shadow.
- **Dangling Price Tickets:** Each piece displays a miniature price tag ticket suspended beneath the neckline.
- **Active Garment Tracker:** Real-time bottom-left metadata (`Hoodie / $199.00`).
- **Quick-View Modal (`GarmentQuickViewModal.tsx`):**
  - Suspended isolated garment presentation with hanging cord.
  - Front / Back angle toggle.
  - Size pills (`S`, `M`, `L`, `XL`).
  - Tactile "Add to cart" with instant added confirmation and "View cart →" prompt.
