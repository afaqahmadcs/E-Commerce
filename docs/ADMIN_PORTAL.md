# AFAQ SUPPLY — Admin Management Portal

## 1. Overview
The **Staff Administration Portal** (`/admin`) provides full commercial and logistical control over the storefront, inventory, dispatches, promotional campaigns, and brand parameters.

---

## 2. Dashboard Modules
1. **Overview Analytics:** Total revenue ($128k+), fulfillment dispatches, active patrons, and in-stock silhouette tracking.
2. **Products Management:** Full CRUD interface to create new silhouettes, set SKUs, adjust pricing, manage sizes and categories, and toggle published/draft statuses.
3. **Orders Pipeline:** Complete dispatch ledger with customer details, payment methods, and live fulfillment status updates (`Pending` → `Confirmed` → `Processing` → `Shipped` → `Delivered` → `Cancelled`).
4. **Collections Manager:** Create and curate seasonal drops with associated silhouettes.
5. **Promotions & Global Ticker:** Live editor for the global announcement bar text and free shipping threshold configuration.
6. **Store Settings:** Persist contact details, brand name, currency code, and gateway parameters.
